My p5.js Animation

About the Project

This project shows an animated object moving in a circular path. It uses mathematics and coding to control its movement.

Controls

  • SPACEBAR: Pause or Resume animation.
  • UP / DOWN: Increase or Decrease speed.
  • LEFT / RIGHT: Decrease or Increase orbit radius.

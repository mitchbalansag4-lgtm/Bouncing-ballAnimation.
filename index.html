Ball Bouncing Animation

About the Project

This project is a bouncing ball animation created using p5.js. The ball moves around the canvas and bounces whenever it reaches the edges.

It also includes interactive controls that allow users to increase the ball's speed and pause or resume the animation.

How to Use

  • Long Press: Gradually increases the ball's speed.
  • Short Tap: Pauses or resumes the animation.
